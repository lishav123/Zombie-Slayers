# Zombie-Slayers

## Introduction

Hello there, readers! You might be wondering that what did I made, well it's a game without vibe coding, I made to improve my logic and designing skills, In past I have made many games in pygame without using any cutsom functions or classes, because that time back in 2020, I knew about classes but didn't know that when to use them, so as you make more complex problems you will understand when to use what.

The is simple game in 2 modes, **zombie killing mode** and **survival mode**, assets I have used are free, I took it from a website I didn't remember, but if you will go and search in google *free ninja sprites and zombies sprites* you will get the stuff.

## How to play this game?

Playing this game is easy 3 step, just you need to have **Python** and **git** on your machine, or you can also download it from **Github** itself.

**Step 1:** Clone the repo

```bash
git clone the-repo-link
```

**Step 2:** Install pygame in your machine.

```bash
pip install pygame
```

**Step 3:** Execute the main file

```bash
python main.py
```
